# Panificadora & Empório Dona Clara

## 📌 Sobre o projeto

O **Panificadora & Empório Dona Clara** é um projeto acadêmico de desenvolvimento web criado com o objetivo de desenvolver uma interface responsiva para uma panificadora e empório fictício.

O projeto apresenta uma solução digital para divulgação de produtos, consulta do cardápio, realização de solicitações de encomendas e acesso às informações de contato do estabelecimento.

A proposta foi desenvolvida considerando princípios de organização visual, usabilidade, responsividade e identidade visual.

## 🎯 Objetivo

Desenvolver um site responsivo, organizado e intuitivo que represente a presença digital de uma panificadora, permitindo ao usuário:

* Conhecer o estabelecimento;
* Consultar produtos disponíveis;
* Visualizar informações sobre pães, doces e salgados;
* Preencher uma solicitação de encomenda;
* Consultar informações de contato e localização.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap 5
* Git
* GitHub

## 📄 Páginas do projeto

### Início

Apresenta a proposta da Panificadora & Empório Dona Clara, seus principais produtos e chamadas para acesso às demais áreas do site.

### Cardápio

Organiza os produtos disponíveis nas categorias:

* Pães
* Doces
* Salgados

### Encomendas

Apresenta um formulário para solicitação de encomendas, com campos para informações do cliente, produto, quantidade, data e observações.

### Contato

Disponibiliza informações de contato, localização e um formulário para comunicação com o estabelecimento.

## 🎨 Identidade visual

A identidade visual do projeto foi desenvolvida com uma proposta acolhedora e relacionada ao segmento de panificação.

### Paleta de cores

* Creme
* Marrom
* Terracota
* Verde oliva

### Tipografia

* **Playfair Display**
* **Poppins**

A combinação dos elementos busca transmitir uma identidade visual artesanal, acolhedora e profissional.

## 📱 Responsividade

O projeto foi desenvolvido para apresentar uma experiência adequada em diferentes tamanhos de tela, utilizando recursos do **Bootstrap 5** e estilos responsivos em CSS.

## ▶️ Como executar

Por se tratar de um projeto desenvolvido com HTML, CSS e Bootstrap, não é necessário realizar uma instalação específica para executá-lo.

Para visualizar o projeto:

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize o menu de navegação para acessar as demais páginas.
